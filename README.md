# mauriciouyaguari.com

Personal site for Mauricio Uyaguari. Next.js (App Router) + Tailwind, deployed on Vercel.

All the text lives in `src/content.ts`, so most updates are edits to that one file.

```bash
npm install
npm run dev   # http://localhost:3000
```

The original 2018 GitHub Pages site is preserved under the `v1-2018` tag.
